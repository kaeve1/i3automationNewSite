# I3 Automation Site

Projeto de site e automação para o sistema I3.

## Conteúdo do Repositório

- **I3AutomationSite/** - Código principal do site e automação
- **logo/** - Recursos de logo/branding
- **mudanca/** - Documentação de mudanças e versões
- **quadrados/** - Componentes e recursos de interface

## Primeiros Passos

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/i3-automation-site.git
   ```

2. Instale as dependências:
   ```bash
   cd I3AutomationSite
   npm install
   ```

## Estrutura do Projeto

```
I3AutomationSite/
├── site/          - Arquivos do site
├── ferramentas/   - Ferramentas auxiliares
├── melhorias/     - Melhorias propostas
├── referencia/    - Documentação de referência
└── fonte/         - Arquivos de fonte
```

## Notas Importantes

- Vídeos de demonstração estão no diretório `Videos/` (não incluído no repositório por tamanho)
- Configurações locais (.env) não devem ser commitadas
- Consulte o arquivo `.gitignore` para ver quais arquivos/diretórios são ignorados
