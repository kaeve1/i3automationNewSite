design.md §2.1

A família

Outfit é sans-serif geométrica arredondada e fonte variável: um arquivo cobre os pesos 300 a 500. São dois .woff2 (latin e latin-ext) servidos de site/fonts/, com unicode-range para o navegador só baixar o que a página realmente usa — em EN-US, o latin-ext quase nunca desce.

Uma família só para tudo. Sem fonte de display separada, sem serifa, sem “fonte industrial pesada”. A única exceção é a monoespaçada de sistema, para dado técnico (UEI, CAGE, NAICS, tags). 

--font: "Outfit", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
--mono: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;

@font-face {
  font-family: "Outfit";
  font-style: normal;
  font-weight: 300 500;        /* variável: um arquivo, três pesos */
  font-display: swap;
  src: url("/fonts/outfit-latin.woff2") format("woff2");
  unicode-range: U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA,
                 U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122,
                 U+2191, U+2193, U+2212, U+2215, U+FEFF, U+FFFD;
}
/* + o mesmo bloco para outfit-latin-ext.woff2 com o range estendido */

design.md §2.3

Os pesos

Três pesos, e a distribuição é o inverso do reflexo comum: quanto maior o tipo, mais leve ele fica. Título de 200px em 300; botão de 16px em 500. É essa inversão que dá a assinatura visual do sistema — se um título grande aparecer em 600, o sistema quebrou.

300

H1, H2, números de credibilidade. Todo tipo grande.

Since 2000, control systems that hold.
400

Corpo, lead, H3. O peso padrão de leitura.

Since 2000, control systems that hold.
500

Nav, botão, CTA, eyebrow, strong, dado técnico. O teto absoluto.

Since 2000, control systems that hold.
700

Não existe no arquivo. O que você vê abaixo é falso-negrito.

Since 2000, control systems that hold.

Isto não é uma fonte, é um defeito. O arquivo variável cobre 300–500; pedir 700 faz o navegador sintetizar o negrito engrossando o traço por conta própria. Repare nas junções empastadas e no espacejamento que não fecha. Por isso strong é 500 no sistema, nunca bold.

design.md §2.3

Por que o tracking negativo

O mesmo texto, no mesmo tamanho. À esquerda, com o que o navegador entrega por padrão (peso 400, entrelinha 1.4, tracking normal). À direita, com os valores do sistema. Em tipo grande, o espaço entre letras cresce junto com o corpo — o -.01em devolve a densidade, e o peso 300 tira o excesso de tinta.

padrão do navegador
Good control strategy beats more expensive instrumentation
sistema · 300 / 1.05 / -.01em

design.md §2.4

Medida e contenção

Largura de linha é regra de tipografia, não de layout — por isso vive em ch, que acompanha o tamanho do tipo, e não em pixel. Quatro medidas, cada uma com um papel.

46ch · .lead e .cabecalho__lead

We build, program and commission the control systems that run oil & gas facilities, treatment plants and solar sites across the United States.

62ch · .corpo

Since 2000 we have delivered 279+ projects worldwide, 158+ across the United States and 78+ in Florida. Our teams work daily on Rockwell, Siemens and Schneider platforms, and we maintain PI System deployments carrying more than 150,000 historized tags. Good control strategy beats more expensive instrumentation.

18ch · h1 de página interna

Water and wastewater treatment

22ch · rótulo de número (dd)

Historized tags maintained across PI System deployments

p           { hyphens: auto; -webkit-hyphens: auto; text-wrap: pretty; }
h1,h2,h3,h4 { hyphens: none;  text-wrap: balance; }
.tabular    { font-variant-numeric: tabular-nums; }

text-wrap: balance nos títulos é o que mais aparece em EN-US: ele impede a última linha órfã de uma palavra só. O hyphens: auto veio do PT-BR e quase nunca dispara em inglês — fica porque não custa nada e ainda pega termo técnico longo (instrumentation, commissioning).

design.md §2.5

Links em texto corrido

Sublinhado só em link dentro de parágrafo. Link de nav, de card e de CTA nunca é sublinhado — cada um tem seu próprio sinal (a régua que cresce, o chip que desliza).

Our capability statement lists every platform we are certified on, and the full past performance record is available on request. For federal contracting, our UEI and CAGE registration is current in SAM.gov. 

p a, li a.link {
  text-decoration: underline;
  text-decoration-thickness: 1px;
  text-underline-offset: 3px;
  transition: color .18s ease;
}
p a:hover { color: var(--navy-hover); }
CLAUDE.md · regra crítica 2

O que não se negocia

A tipografia é o único componente do projeto herdado exato, a pedido. Nenhum valor desta página muda sem confirmação explícita.

  1. 1 Título grande = peso leve. H1 e H2 em 300. Quanto maior o corpo, mais leve o traço.
  2. 2 Nada acima de peso 500, em lugar nenhum. Inclusive strong. Acima disso o navegador sintetiza e o traço empasta.
  3. 3 Uma família só. A monoespaçada de sistema é a única exceção, e só para dado técnico.
  4. 4 Nenhuma media query de tipo. A escala inteira é clamp(). Se apareceu um font-size dentro de @media, está errado.
  5. 5 Fonte servida localmente. Dois .woff2 em site/fonts/, com font-display: swap. Nunca CDN.
  6. 6 Sem caixa alta em bloco. Só em rótulo de até três palavras — o sistema não tem tracking positivo suficiente para caixa alta longa ser legível.
  7. 7 Medida em ch, não em pixel. 46ch para lead, 62ch para corpo, 18ch para h1 interno, 22ch para rótulo de número.
  8. 8 Dígito em coluna pede tabular-nums. Número de credibilidade, tabela, preço, data.

Fontes destes valores — nenhum foi medido no site renderizado.
